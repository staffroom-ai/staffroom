# @staffroom/templates

Staffroom office templates: studio, agency, ecommerce, clinic, consultant.

Part of **[Staffroom](https://github.com/staffroom-ai/staffroom)**: an open-source
3D office where AI agents with roles do real work. Every agent can run on a
different model. Tools come from any MCP server or from a single file you write.

> **Pre-release.** This version is a placeholder that holds the name. The first
> working release is `0.1.0`, scheduled for 27 October 2026. Watch the repository
> for progress.
